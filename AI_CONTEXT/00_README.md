# 保温试验管理｜AI 交接包

本目录是可单独交给本地 DeepSeek 的精简项目上下文。它不包含整份 HTML，也不依赖既往聊天记录。对应代码版本与本机路径见 `03_CURRENT_STATUS.md`、`08_FILE_MAP.md`。

## 建议阅读顺序

1. `01_CURRENT_SPEC.md`：本包**唯一现行业务规则**；遇到冲突以它为准。
2. `03_CURRENT_STATUS.md`：当前版本、Git 快照、测试与待验证事项。
3. `02_ARCHITECTURE_INDEX.md`：函数名、职责、搜索关键词；用于定位代码。
4. `04_REGRESSION_CHECKLIST.md`：改动前后最小测试。
5. `07_DEEPSEEK_PROMPT.md`：直接复制给本地模型的维护指令。
6. 其余文件按需读取：短版本记录、历史/SOP、实际路径。
